AI 설정

Claude가 내 차례인지 판단하고 답장을 쓸 때 읽는 근거와 모델입니다. 근거는 내 Slack 메시지로 학습한 내용, 내가 등록한 프로젝트, 내가 쓴 지침입니다.

내 담당 업무

1차 판단과 초안이 내 담당과 무관한 대화를 거를 때 씁니다. 여러 개면 쉼표나 줄바꿈(Enter)으로 나눠 넣습니다. 모두 빼면 내 Slack 메시지로 말투를 학습할 때 뽑은 값을 씁니다.

내 프로젝트

내가 맡은 프로젝트 폴더입니다. 키워드는 두 곳에 씁니다. 나를 부르지 않아도 내가 있는 채널에 키워드가 나오면 대화를 감시에 올리고(이런 대화는 자동 전송하지 않습니다), 1차 판단과 초안이 내 담당인지 가릴 때 근거로 읽습니다. 너무 흔한 단어는 빼 두세요. 키워드는 폴더 이름·package.json·pubspec.yaml·README 제목에서 자동으로 뽑고, 쉼표로 나눠 고칠 수 있습니다.
초안의 '코드 보고 다시 쓰기'를 누르면 이 폴더들의 코드를 읽고 답장을 다시 씁니다. 코드는 읽기만 하고 .env·키 파일은 읽지 않습니다. 확인한 내용은 노트로 남겨 다음에 먼저 찾아보고, 코드로 확인한 내용이 들어간 초안은 자동 전송하지 않습니다.

내 지침

1차 판단과 답장 초안을 쓸 때 Claude가 함께 읽는 규칙입니다. 말투 분석 결과와 다르면 이 지침을 따릅니다. 입력칸 밖을 누르면 저장되고, 비우면 쓰지 않습니다. (2000자까지)

모델

답장·요약은 이 컴퓨터의 Claude Code로 만듭니다. 대화마다 다르게 하려면 대화 상세 위의 "이 대화 모델"을 쓰세요.
기본 모델내 차례 판단(DM)과 답장 초안을 씁니다
1차 판단채널 스레드는 이 모델이 먼저 "내 차례인지"만 보고, 내 차례일 때만 기본 모델이 초안을 씁니다. 싼 모델일수록 비용이 줄어듭니다
코드 탐색'코드 보고 다시 쓰기'에서 코드를 찾는 모델입니다. 답장은 기본 모델이 씁니다

응답 · 자동 전송

응답 타이밍

메시지가 온 뒤 언제 판단할지 정합니다. 링크로 등록한 대화는 등록하자마자 판단합니다. 판단하는 중에 온 메시지는 그 판단이 끝나면 이어서 판단합니다.
나를 부른 메시지 · DM첫 메시지부터 이만큼 기다렸다 판단합니다. 그 사이 온 메시지는 기다림을 늘리지 않고 함께 판단합니다
초
눈치 보는 스레드의 나머지 댓글첫 댓글부터 이만큼 모았다가 한 번에 판단합니다. 길수록 호출이 줄어듭니다
초

자동 전송

초안마다 모델이 매긴 위험·확신 점수로 자동으로 보낼지 정합니다. 업무지시·결정, 장애·긴급, 민감은 점수와 상관없이 항상 직접 확인합니다.
자동 전송할 대화여기서 고른 곳에 온 메시지만 자동으로 보냅니다. 뺀 곳은 초안을 승인 대기로 둡니다
자동 전송할 카테고리여기서 고른 종류의 대화만 자동으로 보냅니다
얼마나 맡길까요
초안마다 모델이 점수 두 개를 매깁니다. 위험(0~100)은 확인 없이 보냈을 때 문제가 될 가능성, 확신(0~100%)은 초안이 내 말투·의도에 맞을 가능성입니다. 두 점수는 합치거나 곱하지 않고 아래 기준과 하나씩 비교합니다.
자동 전송할 위험위험이 이 값보다 낮은 초안만 자동으로 보냅니다. 낮출수록 자동 전송이 줄어듭니다
미만
직접 확인할 위험위험이 이 값 이상이면 초안 모드여도 '직접 확인'으로 올려 알립니다. 낮출수록 직접 볼 일이 늘어납니다
이상
자동 전송할 확신확신이 이 값 이상인 초안만 자동으로 보냅니다. 높일수록 자동 전송이 줄어듭니다
% 이상
자동 전송 지연자동 전송할 초안은 이 범위에서 무작위로 기다렸다 보냅니다. 그 사이 대화가 바뀌면 보내지 않습니다
~초

문제 해결

        
invalid_auth / not_authed
토큰을 잘못 복사했거나 앱을 지우고 다시 만든 경우입니다. 토큰 앞뒤 공백 없이 다시 복사하세요.

        
"xoxp-로 시작해야 합니다"
Bot 토큰(xoxb-)을 넣었습니다. OAuth & Permissions의 User OAuth Token을 넣으세요. 안 보이면 매니페스트에 user 권한이 없는 것이니 ①에서 다시 만드세요.

        
"필수 권한이 없습니다"
매니페스트에 권한을 추가했지만 재설치를 안 한 경우입니다. Install App → Reinstall to Workspace 후 새 토큰을 넣으세요.

        
App Token 확인 실패
App-Level Token에 connections:write가 없거나, Socket Mode가 꺼져 있습니다. SettingsSocket Mode에서 켜세요.

        
연결은 됐는데 메시지에 반응이 없음

          • Event Subscriptions의 Subscribe to events on behalf of users에 message.im, message.channels 등이 있는지 확인하세요.

          • 상단에서 일시정지나 자동 감지 OFF가 아닌지 확인하세요.

          • 내가 멤버가 아닌 채널은 이벤트가 오지 않습니다.
