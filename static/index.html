권한을 나중에 바꾸면(매니페스트 수정) Install App → Reinstall을 해야 새 권한이 토큰에 붙습니다. 토큰 값이 바뀌었다면 다시 저장하세요.

      


      

        
문제 해결

        
invalid_auth / not_authed
토큰을 잘못 복사했거나 앱을 지우고 다시 만든 경우입니다. 토큰 앞뒤 공백 없이 다시 복사하세요.

        
"xoxp-로 시작해야 합니다"
Bot 토큰(xoxb-)을 넣었습니다. OAuth & Permissions의 User OAuth Token을 넣으세요. 안 보이면 매니페스트에 user 권한이 없는 것이니 ①에서 다시 만드세요.

        
"필수 권한이 없습니다"
매니페스트에 권한을 추가했지만 재설치를 안 한 경우입니다. Install App → Reinstall to Workspace 후 새 토큰을 넣으세요.

        
App Token 확인 실패
App-Level Token에 connections:write가 없거나, Socket Mode가 꺼져 있습니다. SettingsSocket Mode에서 켜세요.

        
연결은 됐는데 메시지에 반응이 없음

          • Event Subscriptions의 Subscribe to events on behalf of users에 message.im, message.channels 등이 있는지 확인하세요.

          • 상단에서 일시정지나 자동 감지 OFF가 아닌지 확인하세요.

          • 내가 멤버가 아닌 채널은 이벤트가 오지 않습니다.
