# 퇴근 · 출근 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 「일시정지」를 「퇴근」으로 바꾸고, 「출근」을 누르면 밀린 대화마다 초안(승인 대기)과 요약을 만든다. 자동 퇴근 시각도 둔다.

**Architecture:** 상태는 기존 `paused` 설정을 그대로 쓴다. 엔진에 `clockIn()`을 추가해 `reply_state === 'unknown'`인 대화를 `process(key, held=true)`와 `summarize(key)`로 처리한다. 자동 퇴근은 `main.ts`가 30초마다 `crossedTime()`으로 판정한다.

**Tech Stack:** TypeScript (Electron main), node:test, 정적 HTML + 바닐라 JS

**Spec:** `docs/superpowers/specs/2026-10-26-off-work-design.md`

**주의:** 실사용 앱이 자동 전송 모드로 돌고 있다. 검증 중에 앱을 띄우거나 재시작하지 말 것. 화면 확인은 사용자가 한다.

```ts
// 자동 퇴근 판정: 지난번 확인(prev) 뒤부터 이번 확인(now, 포함)까지 사이에 그날의 hh:mm이 있었는지. 자정을 넘는 구간도 본다
export function crossedTime(prev: Date, now: Date, hhmm: string): boolean {
  const [h, m] = hhmm.split(':').map(Number);
  return [prev, now].some((day) => {
    const t = new Date(day);
    t.setHours(h, m, 0, 0);
    return t > prev && t <= now;
  });
}
```
