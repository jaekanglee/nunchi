# 퇴근 · 출근

## 문제

퇴근한 뒤에는 답장을 보낼 필요도, AI를 불러 비용을 쓸 필요도 없다. 다음 날 출근해서 밤사이 온 대화를 한꺼번에 보고 싶다.

지금 있는 「일시정지」(`paused`)가 퇴근 동작을 거의 다 갖고 있다. 일시정지 중에는 메시지가 와도 감시 목록에만 올라가고 판단·초안·자동 전송은 하지 않는다. 예약돼 있던 자동 전송은 승인 대기로 돌아간다. 원격 제어 CLI도 "퇴근 후 SSH로" 쓰라고 안내한다. 빠진 것은 두 가지다.

- 일시정지를 풀어도 그동안 쌓인 대화를 다시 판단하지 않는다. 다음 메시지가 와야 판단한다.
- 정해진 시각에 저절로 멈추는 기능이 없다.

## 목표

- 「일시정지」를 「퇴근」으로 바꾼다. 퇴근 중에는 LLM을 부르지 않는다.
- 「출근」을 누르면 밀린 대화마다 초안을 만들고 요약한다. 초안은 모두 승인 대기로 둔다.
- 자동 퇴근 시각을 정하면 그 시각에 저절로 퇴근 처리한다.

## 범위 밖

- 자동 출근. 휴가나 늦게 출근하는 날에 비용을 쓰지 않도록, 출근은 항상 직접 누른다.
- 앱이 꺼져 있던 동안 놓친 메시지를 따라잡는 기능. 퇴근 중에도 앱은 켜 둔다고 가정한다.
- 전체를 한 장으로 모은 출근 브리핑. 대화별 요약만 만든다.

## 동작

### 퇴근 / 출근 버튼

- 상단 바의 `실행 중 / 일시정지` 선택 상자를 버튼 하나로 바꾼다.
  - 근무 중: 초록색 `근무 중` 표시와 `퇴근` 버튼.
  - 퇴근 중: 주황색 `퇴근` 표시와 `출근` 버튼. 밀린 대화가 있으면 `출근 · 12`처럼 개수를 붙인다.
- **퇴근**: `paused = on`. 나머지 동작은 지금 일시정지와 같다.
- **출근**: `paused = off`로 바꾸고 밀린 대화를 처리한다. 처리할 대화 수를 토스트로 알린다(예: "밀린 대화 12개를 정리합니다"). 처리는 화면을 막지 않고 뒤에서 한다.

### 밀린 대화

- 목록 뱃지가 `unknown`인 대화를 밀린 대화로 본다. 마지막 메시지가 내 것이 아니고, 그 메시지까지 아직 판단하지 않았고, 대화별 모드가 끔(`off`)이 아닌 대화다(`replyState()`).
  - 퇴근 시각을 따로 기록하지 않는다. SSH로 `pause`/`resume`을 했거나 일시정지 중 새로 감시에 올라간 대화도 똑같이 잡힌다.
- 대화마다 다음을 한다. LLM은 지금처럼 동시에 2개까지만 돈다.
  1. 평소와 같은 판단·초안(`process`). 자동 전송 조건을 만족해도 **승인 대기**로 두고, 보류 사유에 `퇴근 중 온 메시지`를 붙인다. 직접 확인(escalate)은 그대로 직접 확인이다.
  2. 대화 요약(`summarize`). 요약 뒤에 새 메시지가 없으면 지금처럼 LLM을 부르지 않는다.
- 출근 처리 중에는 대화마다 뜨는 데스크톱 알림(승인 대기·직접 확인)을 띄우지 않는다. 사용자가 이미 자리에 있고, 수십 개가 한꺼번에 뜨면 방해만 된다.

### 자동 퇴근

- 새 설정 `autoOffAt`: `none` 또는 `HH:MM`(24시간). 기본값은 `none`.
- 설정 → 응답 · 자동 전송 → 응답 타이밍 카드에 "자동 퇴근" 시간 입력을 둔다. 비우면 `none`.
- 앱이 30초마다 확인한다. **지난번 확인 시각보다 뒤이고 이번 확인 시각 이하인 구간에 퇴근 시각이 들어 있고**, 지금 근무 중이면 퇴근 처리하고 알림("퇴근 처리했습니다")을 띄운다.
  - 그래서 퇴근 시각이 지난 뒤 `출근`을 눌러 야근할 때는 다음 날 그 시각까지 다시 퇴근시키지 않는다.
  - 퇴근 시각이 지난 뒤 앱을 켜면 자동으로 퇴근하지 않는다.
  - 자정을 넘는 구간도 판정한다(예: 23:59:50에 확인하고 다음 확인이 00:00:20일 때 `00:00`).

### 그 밖

- CLI `pause`/`resume`은 그대로 둔다. `resume`은 근무 상태로만 바꾸고, 밀린 대화 처리는 하지 않는다. 앱의 `출근`을 눌러야 한다는 점을 도움말에 적는다.
- `paused` 설정 설명을 퇴근에 맞게 고친다.

## 구현 위치

- `src/workClock.ts` (새 파일): `crossedTime(prev, now, hhmm)` 순수 함수.
- `src/ctl/settings.ts`: `autoOffAt` 설정, `paused` 설명.
- `src/engine.ts`: `process(key, held)`에 출근 처리 표시를 넘긴다(자동 전송 → 승인 대기, 보류 사유, 알림 생략). `clockIn()`은 밀린 대화 수를 바로 돌려주고 처리는 뒤에서 한다.
- `src/main.ts`: `work:clockIn` IPC, 30초 자동 퇴근 타이머.
- `src/preload.ts`: `clockIn`.
- `src/ctl/index.ts`: 도움말 문구.
- `static/index.html`: 상단 바 버튼, 자동 퇴근 입력, 설정 요약 문구.
- `README.md`: 사용법과 설정 레퍼런스.

## 검증

- `crossedTime`: 구간 안 · 밖, 경계(prev와 같은 시각은 제외, now와 같은 시각은 포함), 자정을 넘는 구간, 퇴근 시각 뒤에 앱을 켠 경우.
- `autoOffAt` 값 검사: `19:00`, `none`은 통과하고 `25:00`, `7:00`은 거부.
- 엔진 `clockIn`: 밀린 대화만 고르는지(내 말이 마지막인 대화, 이미 판단한 대화, 끈 대화는 빠짐), 자동 전송 조건이어도 승인 대기와 보류 사유, 알림을 띄우지 않는지, 요약을 부르는지.
- `npm test`(tsc 포함) 통과. 인라인 스크립트 문법 검사.
- 실사용 앱이 자동 전송 모드로 돌고 있으므로 앱을 띄우거나 재시작하지 않는다. 화면은 사용자가 재시작해서 확인한다.
